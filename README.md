# DCS-Community-A-4E-Guided-weapons-submod

This submod add laser guided weapons and HARM missiles tu the Community A-4E

I 'm not the author of the whole A-4E-C.lua file. I only added the following weapons:
- GBU-10/12/16 single and with double and triple racks
- AGM-88C HARM
- AKWS single and with double and triple racks

The Skyhawk doesn't have lasing capabilities, so the laser guided weapons must be used with buddy lasing.
you can use the HARMs as bigger and more capable shrikes (of coures you don't need to change the seeking head)

How to install:
exstract the A-4E.lua file and replace the original file in C:\Users\**your username**\Saved Games\DCS\Mods\aircraft\A-4E-C.
I sugget to use a mod manager.

The A-4E-C.lua file i modified comes from the Community A-4E-C v2.3 (https://github.com/Community-A-4E/community-a4e-c/releases/tag/v2.3)
